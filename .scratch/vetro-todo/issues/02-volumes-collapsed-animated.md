## Implementation notes

`MangaChaptersPage.kt`:

1. `collapsed` → `expanded` (как предписал архобзор). Пустой дефолт теперь сам по себе означает «все тома свёрнуты» — не нужно набивать состояние ключами всех групп и следить, чтобы оно не разъезжалось при смене фильтра.
2. `val isExpanded = group.label == null || group.key in expanded` — группа без заголовка всегда развёрнута.
3. `ChapterRow` получил параметр `modifier: Modifier = Modifier` (идиоматично для Compose и нужно для анимации), применён к корневому `Row`.
4. Строки глав анимируются через `Modifier.animateItem(fadeIn/placement/fadeOut)` с пружиной `MotionTokens.seasonExpansion()`.

Про пружину: `seasonExpansion` — токен разворачивания групп сезонов в Details. Тома здесь ровно тот же жест, поэтому взят существующий токен, а не заведена новая пружина.

`animateItem` выбран вместо `AnimatedVisibility` осознанно: строки живут внутри `LazyColumn` и при сворачивании физически удаляются из списка, а не скрываются — `AnimatedVisibility` в этом случае не отработал бы.

## Deviations

- **Планировалось:** только правка состояния и обёртка анимации.
- **Сделано дополнительно:** `ChapterRow` получил параметр `modifier`.
- **Причина:** без него анимацию не к чему прицепить; альтернатива — обернуть каждую строку в лишний `Box`, что добавило бы узел разметки на каждую из сотен строк.
- **Последствия:** публичная (в пределах файла) сигнатура приватного композабла расширена, вызывающий один.
- **Follow-up:** не требуется.

## Review findings

- **Риск «манга без томов» закрыт явно.** `groupByVolume` при отсутствии томов отдаёт одну группу с `label = null`, у которой не рендерится `VolumeHeader`, то есть нет переключателя. Наивная инверсия дефолта спрятала бы все главы без способа их открыть. Условие `group.label == null ||` снимает это.
- **Состояние переживает скролл** — `expanded` держится в `remember` на уровне экрана, вне `LazyColumn`, переиспользование строк на него не влияет. Как и раньше, это `remember`, а не `rememberSaveable`: пересоздание процесса состояние сбросит. Поведение не изменилось относительно исходного кода — регрессии нет, отдельной задачей не заводил.
- **Смена фильтра** (All/Unread/Downloaded) пересобирает `groups`, но `expanded` привязан к `state.binding.mangaKey` и сохраняется — развёрнутый том не схлопывается при фильтрации.
- Блокирующих замечаний нет.
