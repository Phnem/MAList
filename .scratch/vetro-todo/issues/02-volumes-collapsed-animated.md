# TICKET-02: Тома в меню глав свёрнуты по умолчанию и анимированы

## Status

PENDING

## Objective

При привязке источника в меню глав все тома изначально свёрнуты; пользователь разворачивает нужный, и это анимировано.

## User or system value

Пункт 10 списка. Сейчас на тайтле с десятками томов открывается простыня из сотен глав.

## Dependencies

Нет — можно начинать сразу.

## Scope

`manga/ui/MangaChaptersPage.kt`:

- строка ~386, `var collapsed by remember(...) { mutableStateOf(emptySet<String>()) }` — пустое множество означает «свёрнутых нет», отсюда и развёрнутые тома. По обзору архитектуры: заменить на `expanded`, тогда пустой дефолт даёт нужное поведение сам собой, без списка ключей.
- строки ~507–519 — чтение/переключение состояния группы.
- тело группы глав — обернуть в анимацию появления/схлопывания.

Шеврон уже анимируется (`:854`) — его не трогать, только согласовать длительность.

## Out of scope

Группировка по томам (`groupByVolume`), формы строк (`groupRowShape`), скачивание тома. Разбиение файла на части (FOLLOW_UP из архобзора).

## Acceptance criteria

- [ ] При открытии меню глав все тома свёрнуты.
- [ ] Тап по заголовку тома разворачивает его, повторный — сворачивает.
- [ ] Разворачивание и сворачивание анимированы, а не мгновенны.
- [ ] Пружина/длительность взяты из `MotionTokens`/`IosDesign`, а не подобраны на глаз.
- [ ] Состояние переживает скролл списка (не сбрасывается при переиспользовании строк).
- [ ] У тайтлов без томов (`groupByVolume` вернул одну группу) список глав остаётся видимым, а не прячется целиком.

## Verification plan

`.\gradlew.bat :app:compileDebugKotlin`. Визуальная проверка — пользователем.

Последний критерий важен: если у манги нет томов, инвертированный дефолт может спрятать вообще все главы. Проверить явно.
