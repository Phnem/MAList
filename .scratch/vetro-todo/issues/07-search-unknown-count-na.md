# TICKET-07: В выдаче поиска «0» эпизодов/глав показывается как «N/A»

## Status

PENDING

## Objective

Когда источник вернул 0 эпизодов или глав, карточка поиска печатает «N/A» вместо «0».

## User or system value

Пункт 8 списка. Чаще всего это Shikimori: «0» читается как «серий нет», хотя на деле источник просто не знает их количества.

## Dependencies

Нет — можно начинать сразу. **Блокирует TICKET-08** (оба правят `ApiSearchResultCard.kt`; сначала показ, потом поведение кнопки).

## Scope

`ui/home/ApiSearchResultCard.kt` — место, где печатается количество эпизодов/глав.

Форматирование вынести в чистую функцию (`Int? -> String`), чтобы покрыть тестом.

## Out of scope

**Хранение.** По решению интервью 2026-07-29 правка только на уровне представления: `AddFromApiUseCase.kt:67` (`episodes.coerceAtLeast(1)`) остаётся как есть, миграции не делаются, уже сохранённые записи с ложной «1 серией» не чинятся. Это принятое ограничение, а не упущение — зафиксировано в `spec.md`, разделы Out of scope и Compatibility.

Карточки коллекции и Details — тоже вне области, правка касается выдачи поиска.

## Acceptance criteria

- [ ] `0` эпизодов в выдаче поиска отображается как «N/A».
- [ ] `0` глав — так же.
- [ ] Ненулевые значения отображаются как раньше.
- [ ] Форматирование вынесено в чистую функцию и покрыто unit-тестом (0, null, 1, большое число).
- [ ] Строка «N/A» одинакова в обеих локалях либо локализована по существующему механизму (`ru`-флаг, как в остальном коде).
