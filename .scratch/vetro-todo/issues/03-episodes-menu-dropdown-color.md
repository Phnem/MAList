# TICKET-03: Фон выпадающего меню в меню серий — `#333333`

## Status

PENDING

## Objective

Выпадающее меню внутри меню серий перестаёт быть залитым чистым чёрным и использует `#333333`.

## User or system value

Пункт 4 списка. Чистый чёрный сливается с фоном тёмной темы, и меню читается как дыра, а не как поверхность.

## Dependencies

Нет — можно начинать сразу.

## Scope

Первым делом — **найти виджет**. Material-компоненты `DropdownMenu` в проекте нет ни разу (проверено grep'ом по всему `app/`), значит меню самописное. Наиболее вероятное место — `ui/details/ModernDetailsEpisodesPage.kt` (там `SeasonMenuHeader`, строка ~326) либо соседние `DetailsEpisodesPage.kt` / `EpisodeQualitySheet.kt`.

Найденный чёрный фон заменить на `#333333`, добавив цвет токеном в `ui/shared/theme/OverlayThemeTokens.kt`, а не литералом по месту (прямое требование архобзора — литералы уже привели к дефекту в п.6).

## Out of scope

Остальные поверхности меню серий, шапка, стеклянные материалы. Прочие чёрные фоны в приложении.

## Acceptance criteria

- [ ] Виджет найден и назван в разделе Implementation notes.
- [ ] Его фон равен `#333333`.
- [ ] Цвет добавлен токеном в `OverlayThemeTokens`, а не захардкожен по месту.
- [ ] Контрастность текста и иконок на новом фоне не хуже прежней.
- [ ] Другие поверхности, использовавшие тот же чёрный, не поехали.

## Verification plan

`.\gradlew.bat :app:compileDebugKotlin`. Визуальная проверка — пользователем.

Если под замену попадает общий цвет, которым залито что-то ещё, — не менять его глобально, а завести отдельный токен для этого меню.

## TDD classification

NOT_NEEDED — цвет. Альтернативная верификация: компиляция + визуальная проверка.

## Expected architecture impact

Плюс один токен в `OverlayThemeTokens`.

## Risks

Если чёрный берётся из общей темы, слепая замена перекрасит половину экранов. Отсюда критерий про «другие поверхности не поехали».
