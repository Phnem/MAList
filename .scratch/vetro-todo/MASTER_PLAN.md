## Verification commands

### Fast checks

```
.\gradlew.bat :app:compileDebugKotlin
```

Базовая линия зелёная на `a224a2b`: `BUILD SUCCESSFUL in 25s`.

**Только `gradlew.bat` через PowerShell.** `./gradlew` в git bash падает с `bad interpreter` (шебанг с CRLF) — и падает молча, если пайпить в `tail`.

### Ticket checks

```
.\gradlew.bat :app:testDebugUnitTest
```

Обязателен для TICKET-07, TICKET-08, TICKET-09.

### Full checks

```
.\gradlew.bat :app:assembleDebug
```

Перед финальным ревью.

**Чего проверить нельзя.** Визуальное соответствие макету, поведение на устройстве с вырезом камеры, «достаточно ли насыщенны» цвета — подтверждает пользователь. Я эти проверки выполнить не могу и не буду записывать их как пройденные.

5. Визуальные критерии (пп. 4, 5, 6) субъективны — вероятны итерации по просмотру пользователем. Это нормальный исход.
