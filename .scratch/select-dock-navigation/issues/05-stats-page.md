## Objective

Развернуть статистику из bottom sheet в полноценную страницу рабочей области, не меняя её содержимого.

## Dependencies

TICKET-01.

## Scope

- Извлечь из `StatsOverlay` содержимое (колода `StatsCardDeckContent`, детальный режим `StatsCardDetailContent`, ИИ-объяснения, футер) в `StatsContent`.
- `StatsPage` — `StatsContent` с шапкой-заголовком, отступом под док, без граббера, без `rememberIosSheetSwipe`, без скрима и без отложенного закрытия.
- `StatsOverlay` остаётся и переиспользует `StatsContent` — при выключенном флаге поведение не меняется.
- Загрузка данных (`loadStatsAnimeList`) на входе на страницу; повторные входы не должны дублировать запросы.

## Out of scope

Любой редизайн статистики: новые метрики, графики, перекомпоновка. Форма подачи — да, содержимое — нет.

## Acceptance criteria

- [ ] Статистика открывается страницей на весь экран, без граббера, скрима и свайпа-вниз
- [ ] Вертикальная колода листается как в шторке, детальный режим по тапу работает, возврат к колоде работает
- [ ] ИИ-объяснения появляются как раньше
- [ ] Данные загружаются при входе на страницу и не перезагружаются лишний раз при листании туда-обратно
- [ ] Горизонтальный свайп на странице листает разделы, а не ломает колоду
- [ ] Back со страницы уводит на Главную (если открыт детальный режим — сначала закрывается он)
- [ ] При выключенном флаге статистика по-прежнему открывается шторкой и работает как раньше
- [ ] Диф не содержит изменений содержимого карточек статистики

## Verification plan

Ручная: обе ветки флага, колода, детальный режим, Back в детальном режиме, светлая/тёмная тема. Сборка.
