# TICKET-09: Статистика в верхний док, панель подключения в настройки

Status: IN_PROGRESS — исправлен пропущенный вид шапки, ждёт проверки на устройстве

## Objective

Убрать статистику из страниц рабочей области, оставив её шторкой: точка входа — средняя кнопка
верхнего дока. Панель подключения и синхронизации, занимавшая эту кнопку, переезжает отдельным
пунктом в настройки.

## User or system value

Пять сегментов в нижнем доке тесны и не оправданы: статистика — эпизодический просмотр, а не
раздел, между которым ходят свайпом. Освободившийся сегмент делает док просторнее, а панель
подключения оказывается там, где её ищут, — в настройках.

## Dependencies

TICKET-01. Заменяет отменённый TICKET-05.

## Scope

- `WorkspacePage`: убрать `STATS`, порядок становится Кадр · Главная · Добавить · Настройки.
- Верхний док (`WorkspaceSortNotificationActions`, `GlassActionDock`): средняя кнопка получает
  режим — панель подключения (старая навигация) либо статистика (рабочая область).
- `HomeScreen`: параметры `showBottomDock` и `useLongPressCardMenu` схлопнуты в один
  `hostedInWorkspace` — все три поведения всегда включаются вместе.
- `SettingsScreen`: необязательный пункт «Синхронизация» (`onOpenSyncPanel`).
- `WorkspaceScreen`: рендерит `NotificationSyncOverlay` поверх пейджера.

## Out of scope

Содержимое статистики и панели подключения. Значок счётчика обновлений на средней кнопке в
рабочей области не показывается: он относится к панели подключения, а не к статистике.

## Acceptance criteria

- [ ] В нижнем доке четыре сегмента: Кадр · Главная · Добавить · Настройки
- [ ] Средняя кнопка верхнего дока в рабочей области открывает статистику шторкой
- [ ] Статистика работает как раньше: колода, детальный режим, ИИ-объяснения
- [ ] В настройках появился пункт «Синхронизация», открывающий прежнюю панель подключения
- [ ] Панель подключения работает как раньше: карточки сервисов, проверка обновлений, выход
- [ ] При выключенном флаге всё по-старому: средняя кнопка — панель подключения со счётчиком, пункта в настройках нет

## Risks

`NotificationSyncOverlay` переехал из `HomeScreen` в `WorkspaceScreen` и теперь берёт данные у
`homeViewModel` напрямую. Под флагом обе копии не существуют одновременно, но при удалении флага
нужно будет убрать копию из `HomeScreen`.

## Implementation notes

Реализовано вместе с TICKET-10 одним проходом.

**Дефект, найденный пользователем на устройстве (2026-08-08):** средняя кнопка по-прежнему
открывала панель подключения. Причина — у шапки главной ДВА вида: `WorkspaceSortNotificationActions`
при `!isHeaderFloating` (список вверху) и `GlassActionDock` при прокрутке. `middleAction`
передавали только второму, первый брал умолчание `SYNC_PANEL`. Пользователь видел именно первый.
Теперь режим и `onOpenStats` получают оба.

Порядок страниц из Scope устарел: с 2026-08-08 он **Главная · Настройки · Добавить · Кадр**
(см. TICKET-11).
