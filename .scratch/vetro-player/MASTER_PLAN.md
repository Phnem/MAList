|---|---|
| D-1 | Автопропуск — **один переключатель на все виды сегментов** (OPENING, ENDING, RECAP, MIXED). Совпадает с тем, как код уже работает: правка только в UI настроек. |

| D-3 | Переключение серий — **резолв внутри плеера**, без выхода на экран выбора. Предзагрузка соседних серий отклонена. |
| D-4 | Пункт 4 — только записать в план, описание отдельным проходом. Реализацию не начинать. |
| D-5 | **Как именно разводить жесты (2026-07-29, вводные пользователя).** Приёмы MX Player / VLC / Just Player, обязательны к реализации: ① число пальцев — первичный фильтр: зум требует ≥2 указателей, свайпы работают только при 1, при втором указателе свайп-обработчик блокируется флагом; ② определение доминирующей оси на первых ~8–16dp движения и её залочивание на весь драг; ③ зональное разделение экрана (левая половина — яркость, правая — громкость, горизонталь — перемотка); ④ состояние зума меняет трактовку драга: при `isZoomed` однопальцевый драг это pan, а не seek; ⑤ debounce после `ACTION_POINTER_UP` — свайпы включаются не сразу, иначе завершение pinch триггерит seek. Реализация: `pointerInput` с явной веткой `size == 2` (scale) против `size == 1` (drag + axis-lock) плюс флаг `isZoomed`. |
