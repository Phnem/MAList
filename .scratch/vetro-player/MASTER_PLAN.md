## Verification commands

### Fast checks

```
.\gradlew.bat :app:compileDebugKotlin
```

**Только `gradlew.bat` через PowerShell.** `./gradlew` в git bash падает с `bad interpreter` (шебанг с CRLF) — и падает молча, если пайпить в `tail`.

### Ticket checks

```
.\gradlew.bat :app:testDebugUnitTest
```

Обязателен для TICKET-02 и TICKET-03.

### Full checks

```
.\gradlew.bat :app:assembleDebug
```

Перед финальным ревью.

**Чего проверить нельзя.** Жесты, реальное воспроизведение, резолв источников по сети, фактическую перемотку сегментов — подтверждает пользователь. Устройства и эмулятора в сессии нет; эти проверки не будут отмечены пройденными.
