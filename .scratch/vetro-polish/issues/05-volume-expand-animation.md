## Objective

Том раскрывается «выпадением» строк и схлопывается «всасыванием», а не подменяет содержимое рывком.
Пункт 4 списка, FR-4.

## User or system value

Тома свёрнуты по умолчанию (сделано в прошлом прогоне), поэтому раскрытие — самое частое действие во
вкладке. Сейчас оно выглядит как сбой отрисовки.

## Dependencies

## Out of scope

- Группировка по томам как правило (`groupByVolume`).

- [x] Схлопывание симметрично: `shrinkVertically` + `fadeOut`.
- [x] Пружина — `MotionTokens.seasonExpansion()` во всех четырёх спеках.

## Expected architecture impact

Меняется структура построения списка: группа тома становится одним элементом с собственной
анимацией видимости вместо россыпи `itemsIndexed`. Это и есть причина отсутствия анимации сегодня —
правка структурная, а не подбор спеков.

## Risks

- Схлопывание всего тома в один `item` делает его главы нелениво измеряемыми. Для тома в 10–20 глав
  это нормально, для группы «все главы без томов» — нет; поэтому она обязана остаться `items`.
- `key` элементов списка меняется — при неверных ключах Compose потеряет состояние строк
  (прогресс загрузки главы).
- `Modifier.animateItem` на строках после смены структуры может конфликтовать с
  `AnimatedVisibility`: одну из двух анимаций надо убрать, иначе они будут спорить.

## Implementation notes

Шапка тома и его тело собраны в ОДИН элемент списка. Раздельными их держать нельзя: `spacedBy`
ставит зазор между элементами независимо от их высоты, и у свёрнутого тома между шапками набегал бы
двойной отступ — дефолтное состояние выглядело бы разреженным.

Отступ от шапки до первой главы живёт внутри анимируемой области, иначе он висел бы под шапкой
свёрнутого тома.

## Deviations

- **Планировалось:** тело тома отдельным элементом с собственной анимацией.
  **Сделано:** шапка и тело — один элемент.
  **Причина:** зазор `spacedBy` применяется и к элементу нулевой высоты (см. выше).
  **Последствие:** главы одного тома измеряются вместе, когда том виден. Для тома в 10–20 глав это
  ничего не стоит; длинные списки без томов остались ленивыми.
  **Follow-up:** не нужен.
