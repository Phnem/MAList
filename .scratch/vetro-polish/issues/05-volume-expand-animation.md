# TICKET-05: Анимация раскрытия и схлопывания томов

## Status

PENDING

## Objective

Том раскрывается «выпадением» строк и схлопывается «всасыванием», а не подменяет содержимое рывком.
Пункт 4 списка, FR-4.

## User or system value

Тома свёрнуты по умолчанию (сделано в прошлом прогоне), поэтому раскрытие — самое частое действие во
вкладке. Сейчас оно выглядит как сбой отрисовки.

## Dependencies

TICKET-04 (общий файл `MangaChaptersPage.kt`). Блокирует TICKET-06 (тот же файл).

## Scope

- `manga/ui/MangaChaptersPage.kt` — структура списка групп: строки тома перестают появляться и
  исчезать как отдельные элементы `LazyColumn` и получают настоящую анимацию высоты.

## Out of scope

- Изменение оформления карточек (скругления, прозрачность) — это TICKET-06.
- Группировка по томам как правило (`groupByVolume`).
- Состояние «какие тома раскрыты» между сессиями.

## Acceptance criteria

- [ ] Раскрытие тома анимировано: строки выезжают, высота списка растёт плавно.
- [ ] Схлопывание анимировано симметрично, без мгновенного исчезновения.
- [ ] Пружина — `MotionTokens.seasonExpansion()`, та же, что у сезонов в Details (FR-4b).
- [ ] Шеврон в шапке тома поворачивается синхронно с раскрытием.
- [ ] Группа без тома (`label == null`) остаётся всегда раскрытой и **ленивой**: её главы не должны
      материализоваться все разом (их могут быть сотни).
- [ ] Скролл списка не дёргается при раскрытии тома, который находится выше видимой области.
- [ ] Клик по шапке во время анимации не ломает состояние.

## Expected architecture impact

Меняется структура построения списка: группа тома становится одним элементом с собственной
анимацией видимости вместо россыпи `itemsIndexed`. Это и есть причина отсутствия анимации сегодня —
правка структурная, а не подбор спеков.

## Risks

- Схлопывание всего тома в один `item` делает его главы нелениво измеряемыми. Для тома в 10–20 глав
  это нормально, для группы «все главы без томов» — нет; поэтому она обязана остаться `items`.
- `key` элементов списка меняется — при неверных ключах Compose потеряет состояние строк
  (прогресс загрузки главы).
- `Modifier.animateItem` на строках после смены структуры может конфликтовать с
  `AnimatedVisibility`: одну из двух анимаций надо убрать, иначе они будут спорить.
