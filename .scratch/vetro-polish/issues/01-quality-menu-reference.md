# TICKET-01: Меню качества по референсу

## Status

DONE

## Objective

Привести `EpisodeQualityPopover` к макету пользователя (фото 2): темнее фон, крупнее скругление,
крупнее карточка и строки, оранжевый прямоугольный бейдж HD, широкий разделитель. Пункт 1 списка,
FR-1.

## User or system value

Пользователь уже дважды правил это меню и оба раза получил «не то». Пункт закрывается только
совпадением с макетом.

## Dependencies

Нет.

## Scope

- `ui/details/EpisodeQualitySheet.kt` — размеры, форма, бейдж, разделитель.
- `ui/shared/theme/OverlayThemeTokens.kt` — `EpisodeMenuSurfaceDark` меняет значение с
  непрозрачного `#333333` на `#1C1C1E` с alpha ≈ 0.96.

## Out of scope

- Светлая тема: материал уровня 2 остаётся как есть.
- Оранжевая обводка чипа-якоря при открытом меню (видна на макете, но пользователь про неё не
  говорил, а чип живёт в другом файле).
- Прочие всплывающие меню приложения.

## Acceptance criteria

- [x] Фон в тёмной теме — `#1C1C1E` с alpha ≈ 0.96 (чуть-чуть просвечивает, D-2).
- [x] Скругление карточки — `IosDesign.RadiusLg` (squircle), крупнее прежнего `RadiusMd`.
- [x] Ширина карточки больше прежних 228dp (ориентир 260dp).
- [x] Высота строки больше прежних 56dp (ориентир 62dp), размер подписи не уменьшен (16sp → 18sp).
- [x] Бейдж HD — скруглённый прямоугольник со сплошной заливкой `BrandOrange` и белой подписью «HD»
      вместо круга 38dp с `primary` 15% и векторной иконкой.
- [x] Левый inset разделителя заметно меньше прежних 60dp (16dp) — линия тянется почти во всю
      ширину.
- [x] Хвостик-указатель на месте (D-1) и красится тем же материалом, что карточка.
- [x] Светлая тема не изменилась (`level2Surface` не тронут; размеры и бейдж общие для обеих тем —
      это заказанная правка формы, а не темы).
- [x] Новых цветовых литералов мимо токенов не появилось (`BrandOrange` — существующий токен).

## Expected architecture impact

Нулевой: правятся значения внутри одного composable и один токен.

## Risks

- `EpisodeMenuSurfaceDark` используется только этим меню — проверить, что других читателей токена
  нет, иначе перекрасится чужой экран.
- Полупрозрачный фон и хвостик: если хвостик рисовать перекрывающимся с карточкой, alpha сложится и
  треугольник станет темнее. Стоять встык, как сейчас.
- Рост ширины до 260dp на узких экранах: карточка обязана оставаться в границах окна — логика
  `coerceIn` по `appView.width` уже есть, но проверить на 260dp.

## Implementation notes

Правка в двух файлах: `EpisodeQualitySheet.kt` (константы размеров, форма бейджа, отступы) и
`OverlayThemeTokens.kt` (значение `EpisodeMenuSurfaceDark`).

Бейдж собран текстом в оранжевой плашке, а не `Icons.Rounded.Hd`: у векторной иконки буквы уже
вписаны в рамку, и поверх собственной подложки получилась бы рамка внутри рамки.

Горизонтальный padding строки приравнен к inset разделителя (16dp) — бейдж и линия начинаются по
одной вертикали, иначе линия «висела» бы левее содержимого.

Проверено, что `EpisodeMenuSurfaceDark` читает только это меню: смена значения ничего больше не
перекрашивает.

## Deviations

Нет. Размеры взяты из `SAFE_DEFAULT` спеки (260/62/16dp) — направление задано пользователем,
числа мои.

## Review findings

- Ширина 260dp на узких экранах: положение уже ограничено `coerceIn` по ширине окна — карточка не
  выйдет за край. Не блокирует.
- Хвостик и карточка стоят встык, не перекрываясь, поэтому alpha 0.96 не удваивается на стыке —
  требование из старого комментария сохранено.

Блокирующих нет.
