# TICKET-07: AnimeGo — лестница алиасов и опознание сезона

## Status

DONE

## Objective

Научить AnimeGo искать русский каталог русскими алиасами и подтверждать, что найденная
страница — запрошенный сезон.

## User or system value

Лог: `animego.me/search/all?type=all&q=Food+Wars!+The+Second+Plate` → 200 → пусто, молча,
трижды подряд. AnimeGo — русский каталог, а запрос ушёл английский, потому что
`scopedToSeason` обнулял `titleRu`.

Отдельно: `AnimeGoSource` жёстко берёт `season = 1` найденной страницы
(`cvh.itemsForEpisode(playlist, season = 1, episode = episode)`). Это верно ровно тогда,
когда страница найдена **по сезонному названию**. После TICKET-04 источник может получить
запрос без доказуемого сезона — тогда допущение перестаёт быть верным.

## Dependencies

TICKET-04 (запрос к источнику с русскими алиасами и признаком доказуемости)

## Scope

Лестница поисковых запросов, по убыванию точности:

1. **Русское сезонное название**, если оно есть.
2. **Русское франшизное название + порядковый маркер сезона** («Повар-боец Сома 2»).
3. **Английское сезонное название** — текущее поведение, теперь последняя ступень.

Плюс:

- Подтверждение сезона: страница принимается, только если её название сходится с алиасами
  запроса по `TitleMatcher`, либо сезон помечен недоказуемым и берётся первый сезон
  страницы (текущее поведение, но теперь явно).
- Лог исхода (в связке с TICKET-01).

## Out of scope

- Резолвер плейлистов `CvhResolver` — работает.
- Скрапинг разметки AnimeGo сверх выбора страницы.

## Implementation notes

Создан чистый шов `media/source/AnimeGoTitleSearch.kt` — у AnimeGo не было ни одного теста,
теперь лестница и подтверждение проверяются без сети.

**`animeGoSearchQueries(SeasonSourceQuery)`** — ступени:

1. Русский алиас с порядковым маркером: `«Повар-боец Сома 2»`.
2. Русский франшизный алиас.
3. Английское сезонное название — прежнее поведение, теперь последнее.

**`animeGoPageMatchesSeason(...)`** — подтверждение страницы:

- совпало с названием самого сезона по порогу → принимаем;
- совпало только с франшизным названием → принимаем лишь для первого сезона либо при
  порядковом маркере в названии страницы.

Это закрывает риск, названный в тикете: франшизный запрос у AnimeGo приводит на страницу
первого сезона, и без подтверждения источник отдавал бы серию не того сезона.

`AnimeGoSource.resolveEpisode` принимает `SeasonSourceQuery` вместо `Anime` и перебирает
ступени по одному запросу, останавливаясь на первой подтверждённой странице. Видимость
метода сужена до `internal` — публичная сигнатура не может светить `internal`-тип.

Хардкод `cvh.itemsForEpisode(playlist, season = 1, ...)` оставлен намеренно: после
подтверждения найденная страница И ЕСТЬ страница нужного сезона, а внутри неё нумерация
своя, с единицы.

## Deviations

- Planned: ступень 2 строит маркер «2 сезон» / «: Второе блюдо» и подобные варианты.
- Actual: маркер один — номер через пробел (`«<франшиза> <N>»`).
- Reason: тикет прямо помечал ступень как дешёвую и необязательную к успеху. Перебор
  словесных форм умножает сетевые запросы, а подтверждение страницы всё равно принимает
  любой заголовок с номером отдельным токеном — то есть «Повар-боец Сома 2 сезон» пройдёт
  проверку, даже если запрос был другим.
- Consequence: нет; при промахе работают ступени 2 и 3.
- Follow-up: нет.

## Review findings

- **Чужой сезон** — закреплено тестом `franchise page is rejected for a later season`:
  страница «Повар-боец Сома» при запросе сезона 2 отклоняется.
- **Ложный маркер** — `ordinal marker requires a standalone token`: «Сома 12» и «Souma 2nd»
  не считаются за сезон 2.
- **Чужой тайтл** — `unrelated page is rejected`: «Наруто 2» не проходит по порогу.
- **Сеть** — ступени выполняются лениво, по одному запросу, с остановкой на первой удаче;
  на успешном пути число запросов не выросло.
- **Архитектура** — AnimeGo выровнен с остальными источниками: чистый слой отделён от сети,
  как в `JutSuTitleSearch.kt`. Пробел в тестируемости из спеки закрыт.
